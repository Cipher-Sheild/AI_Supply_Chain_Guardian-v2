# Recording assets

The files under `fixtures/` are inert scanner inputs, not an application. Never execute the unsafe Python or install the package fixture. The MIT text licenses that demonstration fixture only, not the entire repository.

Use the prompts in order: safe creation, unsafe denial, optional package denial. Keep each in a fresh Copilot Local Agent chat when a prior denial stops the session. Do not ask the agent to bypass its gate. Only the real tool outcome and matching saved scan establish the demonstration.

For the website's detector tour, submit fixtures separately with their original names. `.gitlab-ci.yml` is hidden on Unix file pickers (Ctrl+H shows it); alternatively paste it with that exact filename. Select **Supplied configuration only** for Docker if demonstrating text rules. These fixtures exercise detector routes, not every rule or real-world accuracy. Secret detection is selected on these routes but this bundle contains no real credential.

The PDF filming script in `docs/demo/` contains the complete narration, expected observations, fallback steps and ML caveats.
